# Research material

Result sets, figures, and one-off experiment scaffolding. **Nothing here is needed to
run the app** -- it is kept so the numbers in `docs/` can be traced back to what produced
them.

`make_package.sh.retired` is the script that used to generate a second, slimmed-down
repo (`txm-crack-detector`) from this one. That split was removed in favour of a single
repo; the script is kept only as a record of what the published subset contained.
